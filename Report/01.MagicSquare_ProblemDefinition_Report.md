## 1. 요약

4×4 부분 마방진 학습자가 **10선(행4+열4+대각2, 합 34)** 을 손으로 맞출 때, **대각선 2선 중 1선을 검증하지 않은 채** 진행하다 **늦게** 틀림을 알고 **약 20분**을 재작업에 쓴다.  
본 프로젝트는 **풀이·UI가 아니라 조건 판정(검증)** 으로, 채우기 직후 10선을 빠짐없이 판정해 **판정 지연·시간 낭비**를 줄이는 것을 목표로 한다.

## 2. 페르소나

| 항목 | 정의 |
|---|---|
| **대상** | 4×4 부분 마방진 **학습자** |
| **격자** | 4×4 |
| **빈칸** | 2개 (`0`) |
| **숫자** | 1~16 (중복 없음) |
| **조건** | **10선** — 행 4 + 열 4 + 대각선 2, 각 **합 34** |
| **행동** | 과제·연습 시 **손으로** 빈칸 채우기 (코드 병행 가능하나 1차 증거는 손 풀이) |

## 3. Mom Test — 진짜 문제 vs 표면 문제

### 3.1 진짜 문제 (한 문장)

4×4 부분 마방진(**빈칸 2, 1~16, 10선 합 34**)을 손으로 채울 때, **행4·열4**는 맞춰도 **대각선 2선** 중 하나를 검증하지 않은 채 진행하다가 늦게야 틀림을 알게 되어, **과제에서 20분 가까이** 다시 맞추는 데 쓴다.

### 3.2 표면 문제 (하지 않을 정의)

“4×4 부분 마방진의 **10선(합 34)** 을 자동으로 검증해 주는 **프로그램/앱**을 만든다.”

→ **앱/프로그램 존재**가 목표가 아니라, **늦은 판정으로 인한 재작업 시간**이 문제다.

### 3.3 Mom Test 증거 (과거 사실 인용)

1. “**지난주 OO 과제**에서”
2. “**빈칸 2개 넣고 행·열·대각선 합 맞췄는데**”
3. “**대각선 하나를 빼먹어서 20분 날렸다**”

### 3.4 도메인 ↔ 증거 매핑

| 도메인 | 진짜 문제 | Mom Test 증거 |
|---|---|---|
| 4×4 | 부분 마방진 | (과제 맥락) |
| 빈칸 2 | 빈칸 2 | “**빈칸 2개** 넣고” |
| 1~16 | 1~16 | (4×4 마방진 암묵) |
| 10선 / 합 34 | 10선 합 34, 행4·열4·대각2 | “**행·열·대각선 합** 맞췄는데” |
| 대각선 누락 | 대각선 2선 중 1선 미검증 | “**대각선 하나를 빼먹어서**” |
| 비용 | 20분 재작업 | “**20분 날렸다**” |

## 5. 프로젝트 주제 (솔루션 최소화)

**4×4 부분 마방진(빈칸 2, 1~16, 10선 합 34)을 채운 직후, 10선을 빠짐없이 판정해 늦게 틀림을 알게 되는 시간 낭비를 줄인다.**

- Mom Test 근거: “20분 날렸다” = **판정 지연·비용**
- 1차 범위: **조건 판정(검증)** 만 — 자동 생성·풀이 UI·힌트 없음

---

## 6. R-G-I-O

| | 내용 |
|---|---|
| **Role** | 4×4 부분 마방진 **조건 판정기** |
| **Goal** | 행·열만 맞고 대각선이 틀린 상태를 **채우기 직후** 잡아 재작업 시간(≈20분) 감소 |
| **Input** | 4×4 정수 격자 — `0`(빈칸) 또는 `1~16` |
| **Output** | MAGIC=34 대비 **10축** pass/fail + **어느 축이 틀렸는지** (축 종류·인덱스·실제 합) |

## 7. 성공 기준 (Mom Test 연결)

| ID | 기준 | 증거 |
|---|---|---|
| **SC-1** | OO 과제 형태(4×4, 빈칸 2, 1~16) 입력 → **수 초 내** 10축 판정 | “지난주 OO 과제에서” |
| **SC-2** | **10축** 전부 검사, 하나라도 34≠ → fail | “행·열·대각선 합 맞췄는데” |
| **SC-3** | 행·열 34 OK, **대각선 1개만** fail → **어느 대각선**인지 구분 | “대각선 하나를 빼먹어서 20분” |
