## 1. 페르소나

4×4 격자, **빈칸 2개(0)**, **1~16**, **10선(행4+열4+대각2) 합 34** 맞추는 학습자.

## 2. 인터뷰 기록

### 질문 1
> 4×4 부분 마방진을 **마지막으로** 손으로 채우거나, 코드로 만들어 본 게 **언제**였어요? 그때 **어떤 상황**이었는지 기억나는 대로 말해 주세요.

**답변:**
> “지난주 OO 과제에서 빈칸 2개 넣고 행·열·대각선 합 맞췄는데 대각선 하나를 빼먹어서 20분 날렸다.”

### 질문 2
> 대각선 하나를 빼먹었다는 걸 **언제** 알게 됐어? 그걸 깨닫기 **직전까지** 뭐 하고 있었는지 기억나는 대로 말해줘.

**답변:** *(미응답 — 인터뷰 조기 종료)*

## 3. Mom Test 워크북

### 표면 문제 (잘못된 정의 — 솔루션 포함)
“4×4 부분 마방진의 **10선(합 34)** 을 자동으로 검증해 주는 **프로그램/앱**을 만든다.”

### 진짜 문제 (한 문장 — 솔루션 없음)
4×4 부분 마방진(**빈칸 2, 1~16, 10선 합 34**)을 손으로 채울 때, **행4·열4**는 맞춰도 **대각선 2선** 중 하나를 검증하지 않은 채 진행하다가 늦게야 틀림을 알게 되어, **과제에서 20분 가까이** 다시 맞추는 데 쓴다.

**도메인 ↔ 증거 매핑**

| 도메인 | 진짜 문제 | Mom Test 증거 |
|---|---|---|
| 4×4 | 부분 마방진 | (과제 맥락) |
| 빈칸 2 | 빈칸 2 | “**빈칸 2개** 넣고” |
| 1~16 | 1~16 | (4×4 마방진 암묵) |
| 10선 / 합 34 | 10선 합 34, 행4·열4·대각2 | “**행·열·대각선 합** 맞췄는데” |
| 대각선 누락 | 대각선 2선 중 1선 미검증 | “**대각선 하나를 빼먹어서**” |
| 비용 | 20분 재작업 | “**20분 날렸다**” |

### Mom Test 증거 3줄 (답변 인용)
1. “**지난주 OO 과제**에서”
2. “**빈칸 2개 넣고 행·열·대각선 합 맞췄는데**”
3. “**대각선 하나를 빼먹어서 20분 날렸다**”
