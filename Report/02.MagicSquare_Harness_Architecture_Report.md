## 3. 아키텍처 — ECB

```
boundary → control → entity
```

| 계층 | 역할 | import 규칙 |
|---|---|---|
| **entity** | Grid · Axis · Rule (MS4_RULE_01~06) | **외부 계층 import 금지** |
| **control** | `validate_grid`, `find_violations` 오케스트레이션 | entity만 의존 |
| **boundary** | CLI · 입력 파싱 · E001~E007 | control/entity 위임 |

의존 방향: 항상 바깥→안쪽. 역방향·횡단 import 금지.

---

## 4. Dual-Track TDD

| Track | 계층 | Mock 정책 | 테스트 ID | 파일명 |
|---|---|---|---|---|
| **Logic** | entity, control | **Domain Mock 금지** | `D-*` | `test_d_*.py` |
| **UI** | boundary | **Mock 허용** (I/O·CLI) | `U-*` | `test_u_*.py` |

TDD 순서: **RED → GREEN → REFACTOR**. `assert` 완화 · `skip` · `xfail` 금지.

## 5. 도메인 SSOT (`.cursorrules` 반영)

PRD와 병행하여 `.cursorrules`에 아래를 고정했다.

| 항목 | 규칙 |
|---|---|
| 격자 | 4×4, `0` 또는 `1~16` |
| 빈칸 | **정확히 2개** |
| 마방 상수 | **34** — `MagicConstant` 단일 정의, `34`/`16` 리터럴 산재 금지 |
| 출력 | `int[6]` = `[r1,c1,n1,r2,c2,n2]`, 좌표 **1-index** |
| 오류 | E001~E007 = **boundary** 소유; **entity는 E001~E005 처리 금지** |
